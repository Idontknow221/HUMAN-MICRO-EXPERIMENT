# HUMAN MICRO-EXPERIMENT — v3 每日實驗助理版

## 檔案
| 檔案 | 用途 |
|---|---|
| `index.html` | 完整 App（單檔） |
| `sw.js` | 離線快取，版本升為 `hme-v3` |
| `manifest.webmanifest`、三個 icon | PWA 設定與圖示（未變） |
| `UX_AUDIT.md` | UX 問題盤點、新資訊架構、資料結構 |

**更新方式：** 在 GitHub 上覆蓋 `index.html` 與 `sw.js`。原有紀錄自動沿用，不需轉換。更新前建議先匯出一次 JSON。

## 每天怎麼用
1. 打開「今日」，有底色的那一列是下一件事。
2. 按「開始」，進入執行畫面：一次一步，有計時器；可以上一步、跳過此步、暫停離開。
3. 最後一步按「完成」，接著點 1–3 下快速紀錄，按「儲存」。
4. 早上、睡前各點一次「填寫」（各約 10 秒）。
5. 做不到：按該列的「⋯」→ 今天跳過，或標記不適用。

## 五個入口
| 入口 | 回答的問題 |
|---|---|
| 今日 | 今天要做什麼？（完成數、預估時間與每日預算、今日實驗、早晚紀錄、最近 7 天） |
| 實驗 | 我正在測試什麼？（生命週期、研究證據等級分開顯示、執行步驟、方案版本、變更紀錄、控制、決策） |
| 追蹤 | 我做了什麼？（日曆含漏記標示、完整日誌、客觀測量） |
| 分析 | 有什麼變化？（資料品質 → 執行率 → 主觀 → 客觀；標出基準期與標準差；可看原始數據；週／月回顧） |
| 文獻 | 有什麼依據？（介入方法與研究狀態、56 篇論文、我的方案） |

## 五個使用情境的測試結果
| 情境 | 結果 |
|---|---|
| 1. 早上打開 | 下一個任務在第一屏內，不需要捲動 |
| 2. 執行實驗 | 夢境日記從開始到快速紀錄共 4 次點擊；全程不用離開執行畫面 |
| 3. 完成後紀錄 | 3 次點擊完成（夢數＋1、難易度、儲存）；夢數自動同步到當天日誌 |
| 4. 看近況 | 1 次點擊進入分析；第一區是資料品質；資料不足時直接寫明 |
| 5. 查研究來源 | 文獻 → 方法 → 展開研究依據，3 次點擊看到 DOI 連結 |

## 測試
- 新功能：50 項情境測試全部通過。
- 回歸：24 項回歸測試全部通過，項目如下：
  - 舊資料遷移
  - 週／月統計、月決策
  - 日誌：儲存不重複、未儲存提示
  - 測量：編輯、刪除
  - 候選實驗啟用
  - 資料：JSON 匯出／匯入、CSV、重置、錯誤檔案
  - 凌晨換日
  - 無橫向溢出
- JavaScript 錯誤：0 個。
- 尺寸：iPhone、Android、平板、桌面四種尺寸皆無橫向溢出。

## 自動化的界線
- 今日任務只來自已啟用的方案。
- 超過時間預算時只提醒，不刪減。
- 漏做不補量。
- 少量資料不產生「有效」結論。
- 修改開始日會建立新的方案版本；暫停、恢復、封存、月決策都會寫入變更紀錄。

## 已知限制
- 尚未在真實 iPhone／Android 手機上測試。
- 計時器在背景（鎖螢幕）時不會發出提醒；回到 App 後時間會正確顯示。
- CSV 每個任務欄位記錄的是完成狀態；每次執行的步驟、秒數、難度保存在 JSON 中。
- 研究筆記（Notes）、多實驗比較、AI 分析屬於後續階段，尚未實作。
