## 更新方式（GitHub Pages）
在 repo 網頁上用 **Add file → Upload files** 覆蓋 `index.html` 與 `sw.js`（其他檔案不變）。手機重新開啟 App 一到兩次即可載入新版。**資料不受影響**：localStorage key 仍為 `hme.v1`，資料格式向下相容，不需要遷移。更新前仍建議先匯出一次 JSON。

## 1. 現有功能盤點
| 分類 | 項目 |
|---|---|
| 必須完整保留 | localStorage `hme.v1`、資料結構（days／experiments／measurements／reviews／settings）、實驗 01 的 8 週排程與 WBTB 上限、守門指標規則、候選實驗啟用／暫停／淘汰、週與月統計、JSON 匯入匯出、CSV 匯出、重置確認、凌晨換日、所有 `data-act` 動作 |
| 可改善視覺 | 全站卡片同質化、膠囊標籤過多、圖表缺刻度、證據等級像徽章、文獻像清單 |
| 可改善流程 | 今日頁沒有焦點、近況需要切到進度頁、日誌像問卷、測量只能刪不能改 |
| 需修正的問題 | 日誌切換日期時未儲存的內容會直接遺失；手機鍵盤開啟時底部導覽會遮住輸入區；日誌無法刪除；桌面版只是放大的手機版；圖表在寬螢幕下文字被放大 |
| 不應擅自刪除 | 連續紀錄天數（保留在資料中，但首頁不再強調）、各頁的科學限制說明、FACT／DERIVED／INFERENCE 標示 |

## 2. 新增與改善的設計
- **設計系統**：暖白紙張底色＋深炭黑文字＋低彩度森林綠強調色；琥珀色只用於警示，磚紅只用於危險操作與 D／E 等級。CSS 變數使用 `--color-*` 命名，並有完整的深色模式。
- **字體**：標題用 Noto Serif TC（編輯感），內文用 Inter＋Noto Sans TC，所有數字、日期、ID 使用 IBM Plex Mono 等寬字。離線時會自動退回系統字體。
- **今日**：頁首是日期加「第 N 天」，下方依序是：
  - 單一「今日焦點」區塊。
  - 其餘實驗改為清單列：可直接勾選，點一下展開說明。
  - 今日狀態四項數值。
  - 近 7 天走勢小圖；少於 3 筆時顯示「尚無足夠資料」，不畫線。
  - 近期活動，包含研究庫的更新。
- **實驗**：改為編號索引列表。詳細頁新增「實驗規格表」：目的、每次時間、頻率、原始研究劑量、個人介入劑量、微型版本是否有直接證據、測量方式、狀態、證據等級、守門指標。
- **進度**：分成六個區段：資料品質、行為完成率、主觀感受、客觀測量與實驗結果、階段比較、各項目執行率表。圖表加上刻度與日期標籤；缺漏日留白，不視為 0。
- **日誌**：改為編號條目的研究日誌。新增三個欄位：
  - 今日觀察（橫線筆記紙樣式）。
  - 實驗中的感受。
  - 重要發現：會顯示在近期活動與週回顧。

  其他改善：底部儲存列會顯示「有未儲存的變更」；在有未儲存內容時切換日期會先確認；可刪除單日日誌。
- **文獻**：改為書目條目格式，可依主題篩選。每篇可展開研究對象、介入劑量、主要結果、研究限制、證據層級，以及它支持或反對哪些介入。報告或查證來源中沒有的欄位，直接標示「摘要未整理」。
- **互動**：按下回饋、短淡入頁面切換、勾選動畫；遵守 `prefers-reduced-motion`。表單錯誤直接顯示在表單內，不再用 toast。
- **響應式**：手機用底部導覽；寬度 ≥ 1024px 時改為左側導覽加雙欄版面；平板使用較寬的邊距。

## 3. 修改過的核心程式
| 範圍 | 修改原因 | 影響 |
|---|---|---|
| 第 6–7 節（UI 與頁面） | 重新設計版面 | 只影響畫面；保留 `render`、`saveJournal`、`decisionHint` 等函式名稱與表單 ID |
| 新增 `PAPER_NOTES`、`DOSE`、`RESEARCH_LOG` | 提供規格表與文獻細節 | 唯讀常數，不寫入資料 |
| 日誌新欄位 `obs`、`expNote`、`finding` | 研究日誌需求 | 舊紀錄沒有這些欄位也能正常顯示；CSV 在原有欄位之後新增 3 欄，原欄位順序不變 |
| `openMeasure`／`openCustomMeasure` | 支援編輯 | 依原 `id` 原地更新，不會產生重複紀錄 |
| 事件：新增 `row`、`edit-meas`、`jdelete`；`day`／`gotoday` 加入未儲存確認 | 修正資料遺失與編輯流程 | 其餘 `data-act` 行為不變 |
| `focusin`／`focusout` 加上 `body.kbd` | 鍵盤開啟時隱藏底部導覽 | 只在寬度 < 1024px 時作用 |
| `sw.js` | 快取版本升為 v2 | 舊版快取在啟用新版時刪除 |

## 4. 測試結果（Headless Chrome，Asia/Taipei）
- **功能**：51 項自動測試全部通過，0 個 JavaScript 錯誤。
  - 原本第一版的全部測試。
  - 新功能測試：
    - 清單勾選與復原、列展開
    - 測量的新增、驗證錯誤、編輯、刪除
    - 日誌未儲存提示與確認、刪除日誌
    - 新欄位寫入 CSV
    - 文獻搜尋與主題篩選、文獻細節
    - 鍵盤狀態
- **視覺**：iPhone（390×844）、Android（412×915）、平板（820×1180）、桌面（1440×900），各檢查 6 個頁面，**皆無橫向溢出**；截圖已逐一人工檢查。
- **測試環境限制**：Google Fonts 在測試環境被網路阻擋，畫面以系統備援字體呈現；實機連網時才會載入 Inter／Plex／Noto。

- 更新後操作方式與第一版相同：今日 → 勾選或展開；日誌 → 填寫後按「儲存日誌」。
